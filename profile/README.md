# Cohesive Systems

### Software systems need a language of their own.

We're building **Cohesive**, a language family and semantic compilation platform for expressing what a software system means: its entities, relationships, behavior, workflows, and operational guarantees.

As coding agents make implementation cheaper, understanding what a system should do—and what must remain true through change—becomes the bottleneck. Cohesive gives people and agents a shared, precise representation of that knowledge.

System definitions accumulate into a **semantic system graph**. Compilers and interpreters carry those definitions into APIs, storage, workflows, interfaces, and existing infrastructure. Start with one rule, relation, or process; extend the model as the system grows.

## 🌈 Get involved

Cohesive is evolving through public alpha releases. Help us test the ideas against real systems:

- Try a building block and share what worked, what confused you, and what was missing.
- [Report a bug or propose an improvement](https://github.com/cohesivesystems/cohesive/issues), ideally with a small example.
- Contribute documentation, examples, tests, or adapters. For substantial changes, start with an issue to discuss the design.
- Bring a benchmark: does making system meaning explicit improve correctness, comprehension, or the cost of change?
